# Cinema Fox Admin Dashboard 🦊🎬

لوحة تحكم سينما فوكس السحابية لزحف ونشر الأعمال من MovieBox إلى تطبيق Flutter مع فحص الجودة وروابط الـ HD تلقائياً.

## المميزات
- زحف ذكي لجميع أعمال وفئات موفي بوكس بدون استثناء.
- فحص سلامة روابط البث عبر `HTTP HEAD` وتحديث روابط المعاينة إلى جودة `HD 1080p`.
- واجهة ويب عصرية متوافقة مع الهواتف والحواسب برمز دخول إداري.
- متوافقة تماماً مع النشر السحابي المجاني على **Vercel** على مدار الساعة (24/7).
- توفير واجهة برمجية سريعة `GET /api/catalog` تدعم المزامنة اللحظية مع تطبيق الموبايل (Pull-To-Refresh).

## التشغيل محلياً
```bash
npm install
node server.js
```

## النشر على Vercel
المشروع جاهز ومضبوط بملف `vercel.json` ليعمل كسيرفر سحابي بدون خادم (Serverless) في خطوة واحدة!
